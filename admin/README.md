# Spendit Admin

Admin dashboard for Spendit. It only manages invitation code and app distribution, and DOES NOT monitor user's data.

## Project Setup

To configure the server API for production, you need to add `VITE_SPENDIT_API` in `.env.production` file. For example:

```
VITE_SPENDIT_API=https://your.domain/api
```
